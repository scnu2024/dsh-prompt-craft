# 提示词打磨 · dsh-prompt-craft

[English](README.en.md) | 中文

[![npm](https://img.shields.io/npm/v/dsh-prompt-craft.svg)](https://www.npmjs.com/package/dsh-prompt-craft)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

输入框右侧的一个按钮：把草稿变成**执行者不会误解**的指令，但**不替你做决定**。
结果先浮在输入框上方预览，点一下才写回；缺信息时它问你，而不是编一个 `<占位符>`。

> DeepSeek Harness（DSH）插件，零运行时依赖。

---

## 它和常见的「提示词增强」有什么不同

常见的做法是让模型「把草稿变得更完整」：补目标、补背景、补验收标准、把一句话扩成三段。结果读起来像一份模板公文，还凭空多出你没说过的要求。

这里反过来，只允许三类改动：

1. **消歧**——一句话有两种读法时，选更可能的一种，或把差别变成问题。
2. **补槽位**——只在草稿本身已经给出了值时补；草稿没有的值一律不写，变成问题，或让句子保持笼统。
3. **可执行**——把并列/多步的事排好顺序，去掉重复，只在草稿暗示了形态时点明产出物。

**禁止**：新增任何草稿里没有的事实（日期、数字、路径、文件名、URL、版本、平台、工具、篇幅、受众、验收标准…）、分节标题、四件套模板、开场白、免责声明、凑字数的同义扩写、`<文件路径>`「待补充」这类占位符。

这些禁令不只写在系统提示词里，还有一道**确定性检查**兜底：结果里的新增事实、模板标题、灌水比例、占位符会被逐项比对，命中就带着具体违规项让模型重写一次；重写后仍不合格的版本会带角标明示，**不会偷偷替换成别的内容**。

## 安装

需要 DSH `>=0.2.2-rc.1 <0.3.0` 和 Node `>=22`。装完**重启 Harness**。

从 npm：

```sh
dsh plugin --profile desktop add dsh-prompt-craft   # 桌面版
dsh plugin --profile web add dsh-prompt-craft       # Web 版
```

也可以在「插件 → 插件市场」里搜索安装。从源码：

```sh
git clone https://github.com/scnu2024/dsh-prompt-craft.git
dsh plugin --profile desktop add ./dsh-prompt-craft
```

## 用法

1. 在输入框写下草稿（多短都行）。
2. 点输入框右侧的**打磨**图标。
3. 输入框**上方**浮出结果：
   - 顶部是**要你补的信息**（最多 2 条）——可以当场填，填完点「带着答案重新生成」；
   - 下面是 `标准` 一版（重排到能直接执行，保留你原话能用的部分）。
4. 满意就点「用这版」，文本写回输入框；不满意点「再短一点 / 再具体一点」，或直接关掉。

生成期间可以切走，回来结果还在。应用是普通编辑步骤，`Ctrl+Z` 照常能退回。**它从不发送消息。**

## 设置

`设置 → 提示词打磨`：

| 选项 | 默认 | 说明 |
|---|---|---|
| 我的偏好 | 空 | 一段自然语言，例：`不要分节标题；结论先行；路径写相对路径`。优先级高于默认风格，但不会推翻「不许编造」的规则。 |
| 参考前面的对话 | 开 | 读本会话最近几条消息，避免重复问你已确认过的事。 |
| 高亮改动 | 开 | 预览里把新增的片段用底色标出来。 |
| 用哪个模型 | 跟随当前会话 | 固定某个模型只用于打磨，不影响正常对话。 |

偏好存在 `~/.dsh/prompt-craft/settings.json`（可用 `DSH_PROMPT_CRAFT_SETTINGS` 覆盖），不写 profile 配置。

## 行配置

可选，在 profile 的 `cordis.patch.yml` 里改；都是运维上限，不在设置页暴露：

```yaml
- id: prompt-craft
  name: dsh-prompt-craft
  config:
    maxDraftChars: 6000     # 草稿字符上限
    maxOutputTokens: 3000   # 单次回答 token 预算（截断会自动扩容一次）
    timeoutMs: 60000        # 端到端超时
    contextMessages: 8      # 参考前文最多几条
    contextChars: 6000      # 参考前文的总字符预算
```

## 数据与隐私

- 打磨是一次**走 DSH 宿主模型服务**的调用，用的是你为会话配置的模型（或设置里固定的那个），不经过任何第三方中转。
- 发给模型的内容：草稿、输入框里的附件名、可选的前文片段、你的偏好说明。**不读历史消息里的图片，也不上传任何文件。**
- 两个接口挂在 DSH 宿主已鉴权的连接通道上（`/api/prompt-craft/enhance`、`/api/prompt-craft/settings`），未鉴权请求由宿主直接拒绝。
- 唯一的本地写入是偏好文件；不写 profile 的 `cordis.patch.yml`，不往会话里写事件。
- 无遥测、无外部上报。

## 工作原理

| 半边 | 文件 | 职责 |
|---|---|---|
| Host | `index.js` / `lib/*.js` | 注册两条鉴权路由；读会话投影拿当前模型；组装提示词；调 `ctx.llm`；跑确定性检查并按需重写一次；读写偏好文件。 |
| Client | `client.js` | 输入框按钮、浮层预览面板、设置页；按 `sessionId` 存任务状态；应用时只替换纯文本片段，附件 chip 原样保留。 |

三个值得说明的选择：

- **零依赖**：不引 `schemastery`、不导出 `Config` schema，行配置用防御式读取。
- **答案优先于占位符**：模型被允许「说得笼统」，但被禁止「编一个具体值」。真要具体信息时，它在 `questions` 里问。
- **警告透明**：被检测出问题的版本照常可应用，只是带角标。自动「修正」成另一个意思比不做更糟。

`CONTRACT.md` 是 Host 与 Client 之间的冻结接口，改接口先改那份文档。

## 已知限制

- 不读图片（只把附件名写进提示词）。
- 非流式：整包结果一次返回，生成期间显示骨架。
- 不支持快捷键。
- 切走会话后任务会继续，但刷新页面会丢当前结果（草稿本身不受影响）。
