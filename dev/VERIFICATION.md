## 复现

```sh
npm install
npx playwright install chromium
npm run check
npm test
npm run test:ui
npm run preview:ui
```

预览地址为 `http://127.0.0.1:4178`。顶部可切换主题、场景、设置页和输入框布局。`PROMPT_CRAFT_PREVIEW_PORT` 可指定预览端口，自动测试使用默认端口。
